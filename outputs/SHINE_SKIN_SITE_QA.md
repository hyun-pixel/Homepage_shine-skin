# SHINE SKIN 전체 화면 제작·검수 기록

2026년 10월 17일 · 로컬 디자인 제작 확장 · P01–P09

이 문서는 기존 v4 기록이다. 이번 24종 확장의 최신 검수는 [24종 검수 기록](SHINE_SKIN_CATALOGUE24_QA.md), 현재 규칙은 디자인 명세서 15절을 따른다.

승인된 v3 히어로를 보존하고 PRD의 나머지 디자인 화면과 조작을 연결했다. 실제 쇼핑몰 운영·결제·회원 인증의 완료를 뜻하지 않는다.

## 실제 확인한 것

Windows Edge/Playwright, 127.0.0.1 로컬 정적 서버에서 검사했다.

- **전체 기능 23개 그룹:** 추천, 12종·페이지, 검색 있음/없음, 정렬·복수 필터, 뒤로 가기 복원, 비교 제한/제거, 상세 옵션 필수, 갤러리·확대, 장바구니 합산/선택, 주문 입력/수정/최종 차단, 가입 오류/확인, 로그인 경계, 찜/최근 본, 키보드 모달, 전역 검색, 브랜드, 푸터 모션, 모바일 필터/메뉴, 모션 감소·저장소 차단·손상 데이터 대체를 통과했다.
- **미디어 10개 그룹:** 영상 실제 길이/해상도/시간 진행, 국소 유리 렌더, 기기 모션 설정 실시간 변경, 화면 밖 정지, 모바일 파일 분기, 데이터 절약/영상 실패/WebGL 대체를 통과했다.
- **추가 모바일 3개 그룹:** 하단 옵션 CTA→아래 시트의 색상/수량 승계, 하단 주문 확인→최종 결제 버튼 비활성, 분류에 맞는 제형 사진·확대 연결을 통과했다.
- **최종 수정 5개 그룹:** 홈·검색 조건이 있는 목록·색상을 선택한 상세·입력 중인 주문 화면의 본문 바로가기와 다음 Tab 이동, 모바일 수량 1→2→1의 본문/하단 금액 일치를 통과했다. 주소·조건·입력 보존과 옵션 시트의 값 승계를 확인했다.
- **작은 조작 영역 6개 그룹:** 320/390px × 목록·찜·상세의 관련 상품. 기존 작은 버튼 바깥의 투명 44px 영역을 터치해 정확한 찜/옵션 실행을 확인했다. 옆 비교 버튼과 겹치지 않고 비교 자체도 작동하며, 카드에서 잘리지 않음·아이콘 크기/중심·키보드 포커스·문서 폭을 확인했다.
- **배치 45개:** 9페이지 × 320·390·768·1024·1440px. 문서 가로 넘침 0, 폰트·보이는 이미지 로드, JS 오류·404 0. 비교 표 안의 가로 이동은 의도한 동작이다.
- **사진·한글:** 실제 한글과 생성한 패키지를 넣어 캡처를 확인했다. 브랜드 사진 비율, 두 입력의 행 정렬, 비조작 제목의 초기 포커스 윤곽을 한 번에 보정했다.
- **개인정보:** 검수용 가상 입력으로 이름·주소·연락처·이메일·비밀번호가 localStorage에 들어가지 않음을 확인했다. 외부 HTTP 요청이 없었고, 카드번호·CVC·인증번호 필드는 만들지 않았다.
- **자산 출처:** 7개 래스터 파일의 정확한 프롬프트/출처 sidecar 검사에서 누락 0. 영상의 기존 출처·원본·규격 기록도 유지한다.

결과 원본은 `work/store-checks.json`, `store-mobile-checks.json`, `store-review-fix-checks.json`, `store-touch-target-checks.json`, `liquid-v2-checks.json`, `store-visual-checks.json`이다. 기능 검수는 실제 동작을, 캡처는 해당 상태의 외관을 확인한 것이다. 모든 상태 조합의 접근성 인증이나 실제 기기 성능 보장을 뜻하지 않는다.

## 화면 확인 자료

`.impeccable/review/store/`에 데스크톱·모바일의 9개 페이지와 홈 후반 부분 캡처, 총 22장을 보존했다. 전체 홈은 길어 컬렉션·브랜드 부분을 따로 확인했다. 첫 데스크톱 홈의 폰트 미정착, 전체 캡처 직후 부분 캡처의 합성 레이어 누락은 소스 변경 없이 해당 증거를 다시 캡처해 해소했다.

독립 마감 검토에서 본문 바로가기의 내부 주소 이탈과 모바일 상세의 수량별 금액 불일치 두 건을 수정했다. 같은 22장과 45개 배치를 다시 확인했으며, 최종 판정은 **ship — 두 수정 모두 resolved**다. 이 판정은 해당 수정 목록 범위이며 실기기 등 미검증 범위를 대신하지 않는다. 검토 원문은 `work/full-site-finish-review.md`, 수정 판정은 `work/full-site-finish-verdict.md`에 보존했다.

뒤이은 디자인 일관성 대조에서 작은 카드 조작의 44px 기준 차이를 특정했고, 검토자의 한정 판정에 따라 보이는 크기를 유지하며 투명 터치 영역을 보정했다. 6개 터치 검사·같은 화면 크기 재캡처 뒤 추가 판정은 **ship — 해당 수정 resolved**다. 최종적으로 기록한 수정 3건이 해소됐다. 기준 DESIGN.md와 디자인 토큰 sidecar는 보존했으며 소스 대조 근거·이전 문서의 범위 차이·확인 한계는 `work/full-site-design-consistency.md`에 기록한다.

## 실제 연결하지 않은 것과 남은 검수

- 결제·주문 접수·로그인·회원 생성·이메일/문자 발송·외부 주소 검색·DB·재고·배송 관리·분석/광고·공개 배포는 없다.
- 배송비·배송 약속·환불·약관·사업자 정보·연락처는 제공되지 않아 창작하지 않았다. 주문 요약은 상품금액 합계다.
- 실제 iPhone/Android, Safari/Firefox, 모바일 키보드, 느린 네트워크·저성능 GPU·배터리, 전체 스크린리더 조작·모든 픽셀 대비 검수는 남아 있다.
- 상품명·가격·용량·제품 속성·패키지·제형 사진은 설계 제안이다. 임상·인증·후기·판매 순위·SPF·수상·연혁을 만들지 않았다. 웹 화면의 임시/데모/AI 이미지 표기는 넣지 않았다.
