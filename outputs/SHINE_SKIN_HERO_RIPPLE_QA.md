## 작업 내용과 파일

히어로의 마우스 위치에서 원형 물결이 퍼지고 배경이 굴절되도록 추가했다. 제목·제품 영상·버튼 위로 이미지를 덮지 않는다. 기존 전체 화면 높이·24종·브랜드 이야기·쇼핑 흐름은 유지한다.

- `shine-skin/hero-ripples.js` 신설: 지연 초기화, 유한 시간의 WebGL 물결, 기존 공통 모션 이벤트 공유, 실패 시 기본 화면 유지.
- `shine-skin/index.html`: 장식용 canvas와 지연 실행 스크립트 연결, CSS 캐시 갱신.
- `shine-skin/glass-v2.css`: 물결 레이어·콘텐츠 순서, 모션 축소/호버 없는 환경의 숨김. 모바일 창 크기 변경/포커스로 섹션 내부가 스크롤되는 문제는 `overflow:clip`으로 보정.
- `SHINE_SKIN_PRD.md`·`SHINE_SKIN_DESIGN_SPEC.md`·`SHINE_SKIN_DECISION_LOG.md`·`SHINE_SKIN_REVIEW.html`·`shine-skin/README.md`·`../PRODUCT.md` 갱신. 검토 HTML 생성 원본 `../work/build-review.ps1` 버전 표기도 갱신.
- 검증 원본 `../work/test-hero-ripples.cjs`, `../work/hero-ripple-browser-checks.json`, `../work/hero-ripple-detector.json`. 수정 전 index/CSS는 `../work/hero-ripple-backup/`에 보존.

새 외부 서비스·환경변수·라이브러리·영상·사진을 추가하지 않았다. 기존 로컬 아이리스 이미지를 사용한다. 기존 상품 스크립트·기본 스타일·폰트·영상 파일은 수정하지 않았다.

## 미확인과 남은 한계

실제 휴대전화·Safari·저성능 GPU·느린 통신망의 부드러움과 전력 소모는 확인하지 못했다. 모바일은 브라우저 크기 검사이며 물리 터치 검사는 아니다. 터치 및 데이터 절약·문서 숨김의 새 모듈 동작은 독립 로직 검사로 확인했다. OS의 모션 축소 설정을 직접 바꾸지는 않았으며 공통 푸터 스위치의 실제 동작과 코드의 미디어 조건을 확인했다. 화면 전체를 사용한 효과이므로 실행 시 GPU 작업이 추가되며, 지연 시작·해상도/개수/그리기 상한·화면 밖/입력 종료 시 정지로 제한했다.

사용자가 별도로 설치하거나 설정할 항목은 없다. 추가 유료 기능·외부 전송·실제 결제/회원 생성·공개 배포를 실행하지 않았다. 현재 폴더는 Git 저장소가 아니어서 브랜치가 없으며 commit·push·PR·merge도 없다. 테스트용 화면 크기를 원래2089×1408로 복구하고 히어로를 열어 두었다.

## 2026-10-18 · 배포 후 사각형 번짐 제보 보정

위 기록은 최초 구현 당시의 상태다. 현재 저장소는 `hyun-pixel/Homepage_shine-skin`, 작업 브랜치는 `main`이며 배포 폴더 수정 커밋 `8751eeb` 다음 변경으로 검수했다.

제보 이미지에는 물결 레이어의 사각형 경계와 흰색·청록색 번짐이 보인다. 이 검수 환경에서는 수정 전 같은 흰 사각형을 완전히 재현하지 못했다. 원인을 특정 GPU 문제로 단정하지 않고, 기기별 차이를 만들 수 있는 두 경로를 보강했다.

- 투명 합성: WebGL 컨텍스트를 premultiplied alpha로 명시하고, 출력 색에 알파를 곱한다. 거의 투명한 픽셀은 RGBA 모두0으로 출력한다. 유리 패널의 배경 흐림과 겹쳐도 투명 영역에 색이 남지 않도록 한다.
- 좌표 정밀도: 고정밀 계산을 우선하고 지원되지 않으면 중간 정밀도로 동작한다. 픽셀 좌표의 거리를 제곱하기 전에 화면 크기로 정규화해, 큰 화면에서 중간 정밀도의 수치 범위를 넘길 가능성을 줄인다.
- 캐시 갱신: `index.html`의 물결 스크립트 버전을 `v=9.2`로 갱신했다. 제목·레이아웃·제품 영상·물결 수명과 개수는 유지한다.

참고한 기본 동작은 [MDN getContext의 premultipliedAlpha 설명](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext)과 [Khronos WebGL 정밀도 기준](https://www.khronos.org/files/webgl/webgl-reference-card-1_0.pdf)이다. 이 문서들은 사용자 기기에서의 정확한 재현을 확인한 근거는 아니다.
