# SHINE SKIN 첫 화면 히어로 높이

2026-10-18 · revision 6

사용자는 스크롤 전에는 히어로만 화면을 꽉 채우길 요청했다. 실제 미리보기는 2089×1408px인데 기존 히어로의 최대 높이는 960px이어서 아래 추천 영역이 보였다. 이 제한을 없애고 히어로 최소 높이를 현재 표시 영역 전체로 변경했다. 제목·제품·버튼·유리 재질·영상과 24종 상품 기능은 변경하지 않았다.

수정 파일은 `shine-skin/glass-v2.css`(전체 화면 최소 높이·반응형 예외), `shine-skin/index.html`(이전 스타일 캐시 갱신용 CSS v6 연결), `SHINE_SKIN_DESIGN_SPEC.md` 16절·`SHINE_SKIN_DECISION_LOG.md` 15절 및 이를 반영한 `SHINE_SKIN_REVIEW.html`이다. 현재 화면 사진은 `SHINE_SKIN_HERO_FULL_SCREEN.jpg`, 수치 기록은 `work/hero-viewport-checks.json`, 수정 전 CSS는 `work/hero-viewport-backup/glass-v2.css`에 둔다.

## 확인한 범위

Codex 내장 브라우저의 실제 현재 크기와 화면 크기 변경 기능으로 검수했다. 실제 휴대전화 검수는 아니다.

| 화면 크기 | 히어로 끝·다음 섹션 시작 | 스크롤 전 다음 섹션 | 가로 넘침 |
|---|---|---|---|
| 2089×1408 | 1408px | 보이지 않음 | 없음 |
| 1440×900 | 900px | 보이지 않음 | 없음 |
| 1280×720 | 약 811.55px | 보이지 않음 | 없음 |
| 1024×768 | 768px | 보이지 않음 | 없음 |
| 768×1024 | 약 1135.97px | 보이지 않음 | 없음 |
| 390×844 | 844px | 보이지 않음 | 없음 |
| 320×740 | 740px | 보이지 않음 | 없음 |
| 390×1000 | 1000px | 보이지 않음 | 없음 |

현재 크기·1440px 데스크톱·390px 모바일의 실제 화면을 열어 기존 제품과 제목이 보임을 확인했다. ‘내 루틴 찾기’ 선택으로 #routine 이동·스크롤·고정 헤더 아래 추천 영역 노출을 확인했다. 검수 후 임시 화면 크기 설정을 해제하고 현재 화면의 맨 위로 돌아왔다.

작은 세로 공간에서는 내용의 자연 높이를 허용해 글자·버튼을 자르지 않는다. 화면보다 길어진 히어로는 스크롤로 이어 보며, 추천 영역은 그 뒤에서 시작한다. `100dvh` 미지원 시 `100vh`로 대체한다.

디자인 검사 도구를 이번 수정 파일에 한 번 실행했다(`work/hero-viewport-detector.json`). 기존 유리 경계·그림자·색·글자값과 오래된 기본 효과에 대한 권고가 남아 있다. 이번 높이 변경은 해당 재질·색·타이포그래피 값을 바꾸지 않았으며, 승인된 시각 디자인을 이 요청과 무관하게 바꾸지 않았다. 별도 독립 마감 검토나 전체 쇼핑 기능 33개 그룹을 이번 작은 변경에서 다시 실행한 것은 아니다.

## 남은 확인과 작업 상태

실제 휴대전화의 주소창 변화·Safari·전체 스크린리더·저성능 기기 성능은 미확인이다. 별도 설치·설정·유료 기능·운영 서비스 연결은 필요 없다. 실제 결제·가입·인증·외부 전송·공개 배포도 추가하지 않았다.

현재 폴더는 Git 저장소가 아니므로 브랜치가 없다. commit·push·PR·merge·배포를 실행하지 않았다.
