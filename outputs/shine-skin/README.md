# SHINE SKIN 전체 로컬 디자인

구현 범위: 승인 히어로와 홈 전체, 24종 상품 목록·상세, 비교, 찜·최근 본, 장바구니, 주문·계정 입력 확인, 홈 하단 브랜드 이야기. 실제 결제·주문·회원 인증은 연결하지 않았다.

현재 시안은 파란 아이리스 꽃잎 배경, 배경이 굴절되는 제목 유리 면, 원근이 있는 제품 영상 면을 사용한다. 제품을 감싸는 물줄기는 6초 무음 반복 영상이다. 데스크톱 영상은 약 2.54MB, 모바일은 약 1.27MB다.

## 화면 확인

현재 컴퓨터에서 다음 주소를 연다.

- 비교 화면: http://127.0.0.1:54067/SHINE_SKIN_PREVIEW.html
- 전체 화면: http://127.0.0.1:54067/shine-skin/

비교 화면의 ‘함께 보기’, ‘데스크톱’, ‘모바일’ 버튼으로 전환한다. 홈 아래로 컬렉션·제형·긴 브랜드 이야기·도움말·푸터가 이어진다. 브랜드 메뉴는 홈 하단으로 이동하며 기존 #/brand도 같은 구간으로 연결한다. 상단 ‘전체 제품’에서 24종을 12개씩 둘러보거나 스킨케어·메이크업·선케어의 펼침 메뉴에서 원하는 종류로 이동한다. 작은 화면에서는 오른쪽 위 메뉴 버튼을 누르고 제품군을 펼친다. 제품 상세에서 옵션 선택·비교·찜·담기를 해보고 장바구니에서 주문 내용 확인까지 진행할 수 있다. 기기 설정 또는 푸터의 ‘움직임 줄이기’를 켜면 반복 효과를 멈춘다.

직접 이동: `#/shop`, `#/products/SS08`, `#/compare`, `#/saved`, `#/cart`, `#/checkout`, `#/account`, `#brand`. 주문·계정의 마지막 실행 버튼은 비활성이다. 배송비·약관·운영자 정보 등 실제 운영 설정은 제공되지 않아 만들지 않았다.

주소가 열리지 않으면 이 대화에서 ‘SHINE SKIN 미리보기를 다시 열어줘’라고 요청하면 된다. 별도 설치나 API 키 입력이 필요하지 않다.

## 파일

- `index.html`: 의미 있는 화면 구조와 기본 콘텐츠
- `styles.css`: 기본 디자인 값·반응형 배치
- `glass-v2.css`: 2차 배경·유리 재질·원근·반응형 규칙
- `app.js`: 추천·검색·팝업·로컬 선택 상태·움직임 설정
- `store.css`: 홈 후반·상품·비교·장바구니·폼·브랜드의 반응형 화면
- `store.js`: 페이지 이동·탐색/비교/최근 본·옵션·주문/계정 입력 검증·모바일 시트/구매 바
- `liquid-scene.js`: 제품 영상 재생·정지와 제목 유리의 배경 굴절
- `hero-ripples.js`: 히어로 마우스 위치에서 퍼지는 물결·배경 굴절, 기존 모션 설정 공유
- `assets/`: 제품 이미지·꽃 배경·영상 포스터·화면 크기별 MP4·파비콘·제작 기록
- `fonts/`: 로컬 S-Core Dream·공식 Pretendard 웹 배포본과 이용 조건
- `ASSET_MANIFEST.json`: 이미지·영상 제작 방식·정확한 프롬프트·원본 기록

브라우저 실행 중 외부 API·글꼴 서버·분석 서비스를 호출하지 않는다. 찜·최근 본·비교·장바구니·모션 선호만 현재 브라우저에 저장한다. 이름·주소·전화·이메일·비밀번호는 화면 메모리에서만 사용하고 이동/새로고침 시 제거한다. 카드번호·CVC는 입력받지 않는다. 파일을 공개 서버에 배포하지 않았다.

영상은 화면 밖에서 멈추고, 기기의 움직임 줄이기·데이터 절약 설정에서는 요청하지 않는다. 영상 재생에 실패하면 제품 이미지가 유지된다. WebGL을 사용할 수 없어도 CSS 유리 효과와 콘텐츠를 표시한다.

히어로에서 마우스를 움직이면 그 자리에 물결이 생겨 약1.7초에 걸쳐 퍼진다. 입력이 없으면 남은 물결이 사라진 뒤 그리기를 멈춘다. 터치 환경에서는 이 효과를 시작하지 않으며 ‘움직임 줄이기’와 데이터 절약 설정을 따른다. 기존 꽃잎 이미지로 구현해 추가 이미지 다운로드나 서비스 설정이 필요 없다. 실제 확인과 한계는 상위 폴더의 `SHINE_SKIN_HERO_RIPPLE_QA.md`에 기록했다.

브랜드 통합의 최신 확인은 상위 폴더의 `SHINE_SKIN_BRAND_HOME_QA.md`, 히어로 높이는 `SHINE_SKIN_HERO_VIEWPORT_QA.md`를 참고한다. 이전 24종·카테고리 확장의 확인 결과와 남은 검수는 상위 폴더의 `SHINE_SKIN_CATALOGUE24_QA.md`, 실제 적용값은 `SHINE_SKIN_DESIGN_SPEC.md` 15절을 참고한다. `SHINE_SKIN_SITE_QA.md`는 이전 전체 화면, `SHINE_SKIN_PREVIEW_QA.md`는 이전 대표 시안의 검수 기록이다.
