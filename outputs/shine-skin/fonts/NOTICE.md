# 폰트 출처

- S-Core Dream 3 Light / 4 Regular: 사용자의 로컬 설치 원본 OTF를 그대로 복사했다. 파일 변환·수정·서브셋을 하지 않았다. 공식 이용·재배포 조건: https://s-core.co.kr/company/font/
- Pretendard Regular / Medium: 로컬 TTF에서 Chromium OTS의 `Bad glyph flag` 오류를 확인했다. 같은 글꼴의 제작자 공식 웹 배포 WOFF2를 사용했다. https://github.com/orioncactus/pretendard/tree/main/packages/pretendard/dist/web/static/woff2
- Pretendard 저작권·SIL OFL 1.1 전문: PRETENDARD-LICENSE.txt. 글꼴 파일을 수정하지 않았다.
- 별도 유료 폰트·구독을 사용하지 않았다.
