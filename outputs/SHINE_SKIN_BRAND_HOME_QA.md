# SHINE SKIN 브랜드 이야기의 홈 통합

2026-10-18 · 로컬 revision7

사용자가 첨부한 짧은 유리 배너와 별도 브랜드 이야기 상세 페이지를 없애고, 기존 전체 소개를 홈 하단에 길게 배치했다. 홈은 제품/제형 소개 → 긴 브랜드 이야기 → 도움말 → 푸터로 이어진다. 승인된 화면 전체 높이 히어로·24종·영상·쇼핑 흐름은 유지한다.

## 반영한 내용과 파일

- `shine-skin/index.html`: 기존 배너를 #brand로 교체했다. 기존 제목6개·본문6개·사진2개·루틴/제품 CTA를 옮겼다. 브랜드 제목은 h2, 하위 제목은 h3이며 홈 h1은 하나다. 헤더·푸터 브랜드 링크는 #brand다.
- `shine-skin/store.js`: 독립 브랜드 렌더러를 제거했다. 모바일 메뉴·기존 브랜드 버튼도 #brand로 연결한다. 오래된 #/brand는 이력을 추가하지 않고 #brand로 바꾸며 제목 포커스를 유지한다.
- `shine-skin/store.css`: 사용처가 없어진 배너 스타일을 제거하고 기존 소개의 글꼴·색·배치를 새 제목 단계에 연결했다. 바깥112px/모바일68px, 기존 내부 간격을 유지한다. 640px 실제 화면에서 제목이 좁아지는 것을 확인해 767px 이하에서 두 설명 구간과 세 기준을1열로 보정했다.
- `PRODUCT.md`, PRD·명세17절·결정16절·와이어프레임·문서 뷰어·사이트README를 최신 구조에 맞췄다. P09는 독립 페이지가 아닌 홈 구간의 확대 도식이다. DESIGN.md와 토큰 sidecar는 바꾸지 않았다.

기존 이미지와 문구를 그대로 재사용했다. 새 자산·효능 주장·가격·후기·운영자 정보·유료 서비스·API를 추가하지 않았다. CSS와 경로 스크립트에 v7 계열 연결값을 붙여 이전 캐시가 남지 않게 했다.

별도 레이아웃 검토자는 기존 상세의 2열설명→세기준→CTA를 옮기는 안을 평가했고, 제목 단계·상단 여백·모바일 포커스·중간 폭 확인을 권고했다(`work/brand-home-layout-assessment.md`). 이것을 완성 화면 전체에 대한 독립 ship 판정으로 표현하지 않는다. 최종 화면 검수와 기록은 주 작업자가 수행했다.

추가 확인에서 데스크톱의 같은 #brand 링크를 마우스로 다시 선택하면 본문 위치만 이동하고 포커스가 BODY로 빠지는 경우를 확인했다. 브랜드 앵커를 기존 공통 이동 함수로 처리하도록 한 줄을 보정했다. 최신 스크립트에서 위9개 이동을 재실행했으며, 같은 위치를 키보드와 마우스로 재선택하는 경우도 제목 포커스를 확인했다. 최종 브라우저 결과는 이 보정 뒤의 기록이다.

추가 설정·설치·비용은 없다. 개인정보·결제·가입·인증·외부 운영 서비스·공개 배포를 추가하지 않았다. 현재 폴더는 Git 저장소가 아니므로 브랜치가 없고, commit·push·PR·merge·배포는 실행하지 않았다.
