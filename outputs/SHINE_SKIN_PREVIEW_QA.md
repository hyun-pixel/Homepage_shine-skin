## 자산과 로딩

- 현재 홈의 새 꽃 배경은 약 222KB, 영상 포스터는 약 329KB, 추천 팩샷은 약 177KB다. 이전의 투명 제품 합성 이미지는 연결된 브랜드 패널에서 사용한다. 생성 프롬프트와 원본 기록을 보존했다.
- 제목용 S-Core Dream 원본 2개, 본문용 Pretendard 공식 WOFF2 2개만 사용했다. 본문·제목 글꼴이 실제로 로드되는 것을 확인했다.
- 캐시 없는 로컬 검사에서 영상이 포함된 초기 전송량은 데스크톱 약 6.36MB, 모바일 약 5.08MB다. 원본 폰트 파일도 포함하며 실제 원격 네트워크 측정은 아니다.
- 화면이 뒤늦게 밀리는 정도인 CLS는 위 5개 화면에서 0–약 0.00008이었다. 로컬 환경의 측정값이며 실제 모바일망 성능의 보장이 아니다.
- 제품 영역의 크기를 미리 예약한다. 6초 무음 영상 하나를 사용하고 원본 15.47MB에서 데스크톱 2.54MB·모바일 1.27MB로 줄였다. 자동 재생 오디오는 없다.

## 2차 영상·유리 효과 검수

사용자의 배경·3D 깊이 지적을 반영해 새 꽃 배경, 투명 제목 면의 배경 굴절, 원근이 있는 제품 영상 면을 적용했다. 기존의 전체 히어로 빛 무늬 렌더는 제목 패널 크기로 줄였다.

| 추가 검사 | 확인 결과 |
|---|---|
| 실제 영상 | 데스크톱 960×960, 모바일 640×640, 약 6.041667초·24fps·H.264·무음·반복 |
| 움직임 내용 | 원본 0·2·4·약5.83초 프레임을 직접 디코드해 액체 형상 변화와 제품 라벨 표시 확인 |
| 재생·정지 | 실제 currentTime 진행, 정지 후 시간 고정, 버튼으로 이어보기 |
| 화면 밖 | 히어로가 완전히 화면 밖으로 나가면 video.pause 확인 |
| 모션 축소·데이터 절약 | 영상 파일 요청을 시작하지 않고 포스터 유지 |
| 동영상 실패 | 요청 차단 시 제품 이미지와 본문 유지 |
| WebGL 미지원 | 배경 흐림과 경계의 CSS 대체, 본문·제품 이미지 유지 |
| 렌더 범위 | 검사 환경의 제목 패널 약 648×430px, 20fps 간격 제한. 실제 기기 프레임률을 보증하지 않음 |

추가 10개 검사 그룹과 기존 기능 16개 그룹을 통과했다. 다시 캡처한 5개 너비에서 가로 넘침·글꼴·오류 없는 연결을 확인했다. 브라우저의 일시정지 비디오 캡처에 첫 화면이 남는 현상이 있어, 영상 내용 검증에는 FFmpeg로 직접 디코드한 프레임을 사용했다. 최종 파일은 원본에서 직접 변환했고 길이를 다시 확인했다.

힉스필드 영상 1개 제작의 사전 견적은 10.5크레딧이었다. 기존 사용 허용 범위에서 실행했고 신규 구매·구독·트라이얼 시작은 하지 않았다. 페이지가 실행될 때는 힉스필드와 통신하지 않는다.

## 아직 확인하지 않은 것

- 실제 iPhone·Android, Safari·Firefox, 화면 키보드, 운영체제별 화면 확대·고대비, 스크린리더 전체 조작.
- 저성능 GPU·배터리 사용량·실제 프레임률, 느린 네트워크의 LCP·INP. 제목 유리 렌더의 20fps 간격 제한은 실제 기기 프레임률 검증이 아니다.
- 움직이는 모든 프레임과 모든 메뉴 상태의 픽셀 단위 대비. 고정색 대비와 캡처의 읽기 상태를 확인했으며 공식 접근성 인증을 주장하지 않는다.
- 실제 주문·결제·가입·인증·운영 데이터·외부 서비스. 해당 기능은 이번에 연결하지 않았다.
- 나머지 홈 섹션과 전체 상품 12종의 개별 이미지, 독립 상세·비교·브랜드·주문 페이지.

## 운영·버전 관리

새로운 유료 구독·추가 구매·비밀키·개인정보 수집 설정은 없다. 찜·장바구니만 현재 브라우저 저장소에 보관한다. 분석·광고 추적 코드를 넣지 않았다.

작업 폴더는 Git 저장소가 아니므로 브랜치·커밋이 없다. commit·push·PR·merge·공개 배포는 하지 않았다. 사용자가 직접 API 키를 입력하거나 설치할 것은 없다.

## 1차 시안의 별도 디자인 검수 기록

독립 검수자가 데스크톱·모바일·태블릿·320px·1024px 및 검색·메뉴·제품 패널·비교 화면의 캡처 9개를 확인했다. 모바일 분류명 줄바꿈, 보조 아이콘의 일관성, 추천 조건의 정보 순서 세 항목을 수정했다.

같은 9개 캡처로 다시 검수한 결과 세 수정 항목은 모두 `resolved`, 해당 수정 목록의 최종 판정은 `disposition: ship`이었다. 이 판정은 실제 휴대전화·전체 사이트·전체 접근성 인증을 뜻하지 않는다. 유리 제품 조형·색상·모바일 가로형 카드·모션 제어는 유지했다.

최종 소스에서 공통 규칙을 추출해 작업 루트의 `DESIGN.md`와 `.impeccable/design.json`에 기록했다. 이 두 파일은 이후 화면을 같은 기준으로 만드는 내부 개발 자료이며 웹 화면에 노출되는 설명이 아니다. JSON 해석·정규 문서 섹션·최종 소스의 값 반영을 확인했다.

## 2차 시안의 별도 디자인 검수 기록

새 검수자가 현재 캡처 9개, 거절된 1차 화면, 참조 이미지, 디코드한 영상 프레임, 소스와 재생 검사 결과를 비교했다. 배경이 보이는 유리·꽃잎 공간의 깊이·제품 액체 영상·반응형 구성이 수정 목적에 맞는 것으로 판정했다.

최종 판정은 `disposition: ship`, 추가 필수 수정은 없었다. 적용 범위는 헤더·히어로·추천의 이번 수정이다. 연속 재생의 체감 부드러움은 독립 검수자가 직접 관찰하지 않았으며 실제 휴대전화 성능 검수는 남아 있다. 내부 디자인 규칙에도 2차 재질·배경·영상 동작을 반영했고 JSON 해석·정규 문서 섹션·최종 소스 값 반영을 확인했다.


## 3차 히어로 배치 검수 — 2026-10-17

제목·영상 앞면의 겹침을 없애고 두 열의 비율·간격·영상 최대 폭을 정리했다. 태블릿은 고정 1120px 대신 자연 높이 흐름, 모바일은 24px 간격을 사용한다. 히어로 제품 캡션·하단 문구·수동 모션 버튼을 제거했다. 이전 2차 검수의 수동 버튼 설명은 현재 동작을 뜻하지 않는다.

기존 검사도 현재 UI에 맞춰 갱신한 뒤 다시 실행했다. 16개 기능 그룹·10개 영상/유리 그룹 통과, 320·390·768·1024·1440px에서 본문 가로 넘침 0건·폰트/이미지 로드·콘솔/404 오류 없음. 현재 최대 로컬 CLS는 약 0.00012다. 기기 모션 설정 실시간 전환·화면 밖 정지·데이터 절약/영상 실패/WebGL 대체가 동작한다. 추천·검색·찜·장바구니와 키보드 모달 회귀 검사를 통과했다.

별도 검수는 5개 새 캡처와 이전 시안을 비교해 ship으로 판정했다(work/hero-v3-finish-review.md). 실제 휴대전화·Safari·스크린리더 전체 검수는 아직 진행하지 않았다. 추가 유료 생성·배포·commit/push는 없다. 변경 구현 파일: index.html, glass-v2.css, app.js.
