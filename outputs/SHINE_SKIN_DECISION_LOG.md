# SHINE SKIN 결정 기록

작성일 2026년 10월 16일 · 최종 변경 2026년 10월 18일 · 버전 1.9 · 전체 문구·배치 정리와 최종 검수 반영

인터뷰에서 확정한 내용, 담당자가 제안한 내용, 아직 확인하지 않은 내용을 구분한다. 웹에는 실제 공식몰처럼 자연스럽게 표현하고, 가상 브랜드라는 전제와 제작상 가정은 이 문서 및 [PRD](SHINE_SKIN_PRD.md)에 남긴다.

## 3. 아직 결정하거나 확인하지 않은 내용

| 항목 | 현재 상태와 영향 |
|---|---|
| 개별 상품의 최종 이름·가격·옵션·설명 | PRD의 가상 상품안 검토 필요. 확인된 실상품 정보가 아님 |
| 구체 색상과 패키지·로고 원본 | 시안 제작 전. 이미지가 이미 생성됐다고 주장하지 않음 |
| 실제 효능·전성분·SPF·PA·인증 | 증빙 없음. 창작해 게시하지 않음. 실제 운영 상품으로 전환하면 자료 확보 필요 |
| 배송·할인·환불·재고 정책 | 미정. 현재 흐름은 상품금액 합계와 실행 직전 확인까지만 |
| 약관·사업자·연락처·개인정보 정책 | 운영 주체 자료 없음. 가짜 번호·주소·법률 문안·작동하지 않는 링크 생성 금지 |
| 힉스필드 연결·보유 크레딧·생성 한도 | 계정 상태 미확인. 사용 허용을 추가 결제 승인으로 해석하지 않음 |
| 최종 폰트 조합과 웹 배포 형태 | 파일·라이선스 후보는 확인했으나 실제 브라우저 렌더링·성능은 시안에서 검수 |
| 기술 스택·호스팅·도메인 | 로컬 프런트엔드 방향만 제안. 운영 서비스·공개 배포 미승인 |

## 4. 자료와 확인 범위

### 4.1 사용자 제공 이미지

| 자료 | 확인한 특징 | 활용 |
|---|---|---|
| 이미지 1: 어두운 식물과 유리 숫자 | 유리 가장자리·빛·앞뒤 깊이 | 재질 원칙 참고, 어두운 방향은 선택하지 않음 |
| 이미지 2: 바다와 음악 패널 | 배경이 비치는 패널·곡면 | 유리 원칙 참고, 화면 구조 복제 안 함 |
| 이미지 3: 밝은 파란 꽃과 유리 패널 | 밝은 블루·반투명·얇은 밝은 경계 | 최종 방향의 주 참고 |

정지 이미지이므로 실제 움직임·모바일 동작을 확인한 자료가 아니다.

### 4.2 공식 사이트·서체 자료

- [HERA 공식 사이트](https://www.hera.com/): 메이크업·스킨케어 분류와 제품 탐색 구조를 텍스트로 확인. 전체 상품의 최신 판매 순위를 검증한 자료는 아니다.
- [LANEIGE International](https://int.laneige.com/): 스킨케어 유형·고민·라인, 메이크업, 대표 상품 구성을 확인. 한국 사이트의 일부 주소는 오류 또는 본문 미확인 상태였으므로 해당 화면을 시각적으로 확인했다고 기록하지 않는다.
- [Pretendard 공식 라이선스](https://raw.githubusercontent.com/orioncactus/pretendard/main/LICENSE): SIL OFL 1.1과 저작권·재배포 조건 확인.
- [에스코어 공식 글꼴 안내](https://s-core.co.kr/company/font/): 개인·기업 무료 사용 및 재배포, 파일 수정·폰트 자체 판매 금지 조건 확인.
- 로컬 사용자 폰트 폴더에서 Pretendard TTF와 SCDream OTF를 확인했다. 다른 카페24·페이퍼로지 등은 설치 존재만 확인했으며 모든 글꼴의 개별 사용 조건을 검증한 것은 아니다.

### 4.3 추가로 준비할 자료

이번 시안용 로고·패키지·제품명·사진·문구는 담당자가 새로 제안한다. 사용자가 직접 코드를 작성하거나 폰트를 고를 필요는 없다. 실제 판매 서비스로 전환할 경우에는 운영 주체가 상품 증빙·정책·사업자 정보·결제와 배송 설정을 제공해야 한다.

## 5. 변경 원칙과 승인 단계

| 단계 | 검토 내용 | 다음 단계로 가는 조건 |
|---|---|---|
| G01 문서 | 목적·범위·상품안·실행 경계·디자인 방향 | 사용자 확인 후 대표 시안 제작 |
| G02 대표 시안 | 홈 헤더·히어로·추천 영역의 데스크톱·모바일 | 실제 화면 수정 반영 후 나머지 확장 |
| G03 전체 화면 | 페이지·상태·모션·반응형·접근성 | PRD AC01–AC18 검수 및 결과 보고 |
| G04 외부 연결·공개 배포 | 비용·보안·개인정보·운영 영향 | 별도 설명과 사용자 승인 |

수정이 생기면 관련 D 기록, PRD의 R 번호, 디자인 명세의 해당 화면을 함께 고친다. 색상이나 기능을 실제로 바꿨는데 문서가 이전 상태로 남지 않게 한다.

## 6. 현재 완료와 미실행

완료: 인터뷰 정리, 연결된 PRD·디자인 명세서·와이어프레임·결정 기록 초안 작성, 로컬 폰트 존재와 일부 공식 사용 조건 확인.

미실행: 실제 사이트 제작·브랜드 이미지 생성·회원/결제 연결·사이트 반응형/성능/접근성 검수·유료 구매·공개 배포. HTML 와이어프레임의 문서 표시와 이동 점검은 실제 사이트의 기능 검수와 구분한다.

현재 작업 폴더는 Git 저장소가 아니다. 브랜치·커밋·푸시·PR·병합·배포는 없다. 사용자에게 코드 수정이나 환경변수 입력을 요청할 단계가 아니다.
