# SHINE SKIN 24종·카테고리 확장 검수

2026년 10월 17일 · 로컬 화면 revision 5

사용자가 선택한 **24종 엄선형(2번)**을 반영했다. 기존 히어로와 전체 디자인을 보존하고 상품 구성·헤더 분류를 확장했다. 실제 결제·주문·가입·인증·공개 배포는 연결하지 않았다.

## 변경 결과

- 기존 12종에 클렌징 밤·미스트·에센스·슬리핑 마스크·톤업 선케어·선스틱·파운데이션·컨실러·립스틱·립밤·브로우·마스카라를 추가했다. **스킨케어 10 / 메이크업 11 / 선케어 3 = 24개 고유 제품**이며 색상 옵션은 별도 상품 수로 세지 않는다.
- 헤더는 전체 제품·스킨케어·메이크업·선케어·나만의 루틴·브랜드다. 데스크톱은 유형·개수·대표 제품을 담은 유리 메가메뉴, 1199px 이하는 기존 메뉴 드로어 안의 제품군 아코디언이다. 19개 하위 유형 모두 실제 상품이 있다.
- 전체 목록은 12개씩 두 페이지, 1400px 이상 4열·중간 3열·639px 이하 2열이다. 제품군 아래 유형 메뉴를 추가했고 최신 검색·피부·상황 조건을 보존한다.
- 새 제품도 상세·옵션·가격·찜·최근 본·비교·장바구니를 기존 흐름에 연결했다. 상품·가격·이미지는 내부 설계 제안이며 검증되지 않은 효능·SPF/PA·후기·순위·사업자 정보를 만들지 않았다.

## 직접 확인할 화면과 남은 범위

현재 컴퓨터에서 [홈](http://127.0.0.1:54067/shine-skin/?revision=5) → 상단 스킨케어/메이크업/선케어를 펼쳐 원하는 유형을 선택한다. [전체 제품](http://127.0.0.1:54067/shine-skin/?revision=5#/shop)의 2페이지에는 추가 12종이 있다. 작은 화면은 오른쪽 위 메뉴 버튼에서 제품군을 펼친다. 별도 설치·계정·API 키 설정은 필요 없다.

미확인: 실제 휴대전화·Safari·저성능 GPU·느린 이동통신망·전체 스크린리더·모든 영상 장면의 수치 대비. 기존 모션의 보존과 재생/정지 경계는 기능 검사로 확인했지만 이번 변경에서 새로 실기기 성능을 측정한 것은 아니다.

실제 운영 전에는 원본 상품 자료·가격·법정 표시·배송/환불/개인정보/약관·운영자 정보를 확정해야 한다. 개인정보 입력은 화면 메모리에만 존재하며 영구 저장·외부 전송하지 않는다. 카드번호/CVC 입력은 없고 결제·회원 생성·인증의 마지막 실행은 비활성이다.

현재 폴더는 Git 저장소가 아니므로 브랜치가 없다. commit·push·PR·merge·공개 배포는 실행하지 않았다. 로컬 미리보기 서버만 사용한다.
